# Kilder og rettigheter

Ingen bilder brukes som scene. Alt er geometri, shadere og lys i koden.

| Hva | Opphav | Lisens |
|-----|--------|--------|
| `assets/still.jpg`, `assets/og.jpg` | Rendret fra scenen i dette repoet. | Din. |
| Teksturer (rye, kart, laptopskjerm, bjørkebark) | Tegnet i kode med canvas, i `src/world.js`. | Din. |
| `assets/vendor/three/` | Three.js 0.170.0. | MIT. |
| `assets/vendor/gsap.min.js` | GSAP 3.12.5. | GSAP standardlisens, fri for personlige sider. |
| `assets/ort/ort*.js`, `ort*.wasm`, `ort*.mjs` | ONNX Runtime Web 1.20.1. | MIT. |
| `assets/ort/yolo11n.onnx` | Ultralytics YOLO11n, eksportert til ONNX. | AGPL-3.0. Fri bruk på en personlig, åpen side. |
| Fonter | Fraunces, Source Sans 3, JetBrains Mono via Google Fonts. | OFL. |

Stilrammen og interiørskissen (generert i Canva) ble brukt som fasit for palett, lys og innhold. De ligger ikke i repoet.
